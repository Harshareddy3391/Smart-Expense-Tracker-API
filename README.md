"# Smart-Expense-Tracker-API" 
This project is a simple REST API built using FastAPI for managing personal expenses. It was created as part of the Diligent Software Engineering Apprenticeship 2026 assignment.

The API lets users add expenses, view all expenses, filter them by category, calculate totals, and delete expenses. Instead of using a database, all data is stored in a local JSON file, which keeps the project simple and easy to understand.

---

## Features

- Add a new expense
- View all expenses
- Filter expenses by category
- Calculate total expenses
- Calculate total expenses by category
- Delete an expense
- Store data in a local JSON file
- Swagger documentation
- Automated tests with Pytest
